# Gastric_MultipleRegion_WES

## Code for Figures in the Paper  
**"Evolving Genomic Characteristics of Intestinal Metaplasia and Gastric Cancer"**

This repository contains the scripts used to generate the figures for the paper. Below is an outline of the figure-specific codes and their functionalities.

---

### **Figure 1**  
Focus: Mutation burden, significantly mutated genes, and clonal evolution patterns in IM, IGC, and DGC.

- **Code Files**:
  - `Figure1_gcburden.R`: Analyze mutation burden in gastric cancer (GC).
  - `Figure1_imburden.R`: Analyze mutation burden in intestinal metaplasia (IM).
  - `Figure1_waterfall.R`: Generate mutation waterfall plots.
  - `Figure2_evolutionarymode.R`: Assess clonal evolution modes.

---

### **Figure 2**  
Focus: Comparative analysis of mutation burden and copy number variations (CNVs) in IGC and DGC.

- **Code Files**:
  - `Figure2_mutationburden.R`: Compare mutation burdens in IGC and DGC.
  - `Figure2_cnvburden.R`: Compare CNVs in IGC and DGC.

---

### **Figure 3**  
Focus: Mutation burden, tumor cell fractions, and CNVs in IM.

- **Code Files**:
  - `Figure3_mutationburden.R`: Analyze mutation burden in IM.
  - `Figure3_cnvburden.R`: Analyze CNVs in IM.

---

### **Figure 4**  
Focus: Mutation waterfall plots, mutation rate comparisons, and clonal evolution modes in IM, IGC, and DGC.

- **Code Files**:
  - `Figure4_waterfall.R`: Generate mutation waterfall plots.
  - `Figure4_mutrate.R`: Compare mutation rates.
  - `Figure4_modes.R`: Analyze clonal evolution patterns.

---

### **Figure 5**  
Focus: Mutation waterfall plot.

- **Code File**:
  - `Figure5.R`: Generate mutation waterfall plot.

---

### **Figure 6**  
Focus: Comparison of clonal evolution timing.

- **Code File**:
  - `Figure6.R`: Analyze and compare clonal evolution timings.

---

### **Figure 7**  
Focus: MUC6 mutation distribution, epithelial proportions, cell-cell communication, and differential expression analyses.

- **Code Files**:
  - `Figure7_mutation.R`: Analyze MUC6 mutation type distributions.
  - `Figure7_compareratio.R`: Compare epithelial proportions in mutated vs. wild-type samples.
  - `Figure7_scissor.R`: Perform SCISSOR analysis.
  - `Figure7_cellphonedb.R`: Analyze cell-cell communication using CellPhoneDB.
  - `Figure7_diffexp.R`: Conduct differential expression analysis.
  - `Figure7_pitratio.R`: Compare pit cell proportions.
  - `Figure7_bulk.R`: Analyze bulk RNA-seq data.

---

## **Usage Instructions**
1. Clone the repository.
2. Ensure dependencies for R scripts are installed.
3. Run each script in the specified order for reproducibility of the figures.
